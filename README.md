# Конструктор Васту-карты · Анна Ромео

Веб-конструктор Васту-карты для курса Анны Ромео, написанный с нуля по методу школы С. А. Балуты и требованиям курса.

## Возможности

- **Загрузка плана квартиры** с телефона или компьютера: изображения `JPG`, `PNG`, `WebP` и первая страница `PDF`. Все вычисления проходят полностью в браузере — план квартиры не отправляется на сервер.
- **Направление на Север без внешних онлайн-карт**: поворот стрелки «С» прямо на чертеже, ввод точных градусов и встроенный переводчик показаний компаса телефона с памяткой по замеру.
- **Контур любой формы (в том числе Г-образной и с выступами)**: расстановка внутренних углов касаниями, перетаскивание углов, вставка новой точки на стене, удаление точки, отмена шагов (`Отменить`) и помощник прямых углов `90°`.
- **Геометрический центр квартиры (Брахмабинду)** по её настоящей форме (точное взвешивание площадей по С. А. Балуте).
- **Слои итоговой карты строго по методу школы Балуты**:
  - **8 радиальных секторов по 45°** от географического Севера с палитрой и формулами зон Анны Ромео;
  - **Брахмастан по форме квартиры** (`1/9` площади — внутренняя треть лучей от центра к внутренним углам с отсечением по внешним стенам);
  - **Сетка наложения пад** (`32` радиальные пады по `11,25°` вокруг центра и частотные пояса `1/9`, `3/9`, `5/9`, `7/9`).
  - Слои первоэлементов и квадратного Брахмастана отсутствуют.
- **Сохранение готовой карты в PNG** высокого разрешения (`2400 px`) с легендой секторов и подписью «Васту-карта · Анна Ромео» для прикрепления к домашнему заданию.
- **Полная автономность**: локальные шрифты `Cormorant` и `Manrope`, локальная сборка `pdf.js` — сайт не обращается к внешним CDN, Google или Яндекс.

## Быстрый запуск локально

Требуется установленный **Node.js 18+**.

```bash
# 1. Установить зависимости
npm install

# 2. Собрать локальные шрифты, PDF-модуль и статическую папку dist/
npm run build

# 3. Запустить юнит-тесты геометрии
npm test

# 4. Запустить локальный статический сервер
npm start
```

После запуска откройте в браузере адрес [http://127.0.0.1:4173](http://127.0.0.1:4173).

Также собранную папку `dist/` можно раздавать любым статическим сервером (например, `npx serve dist` или `python3 -m http.server -d dist 8080`).

## Публикация на Render как Static Site

Проект собирается в полностью статическую директорию `dist/` и не требует серверного процесса (Web Service).

1. Подключите репозиторий к **Render**: нажмите **New +** → **Static Site**.
2. Укажите настройки сборки:
   - **Branch**: `main` (или нужная ветка)
   - **Root Directory**: оставьте пустым (корень репозитория)
   - **Build Command**:
     ```bash
     npm ci && npm run build
     ```
   - **Publish Directory**:
     ```text
     dist
     ```
3. Переменные окружения не требуются. Нажмите **Create Static Site**.
4. При желании привяжите собственный поддомен в разделе **Settings → Custom Domains** (Render автоматически выпустит SSL-сертификат).

## Структура проекта

- `index.html` — разметка рабочего стола конструктора
- `styles/main.css` — фирменное оформление Анны Ромео (бордовый `#422326`, тонкое золото `#CABC90`, кремовый `#F4F2ED`, адаптация под телефон и компьютер)
- `styles/fonts.css` и `assets/fonts/` — локальные кириллические и латинские шрифты `Cormorant` и `Manrope` (генерируются командой `npm run build`)
- `src/geometry.js` — геометрическое ядро (площадь, геометрический центр контура, триангуляция невыпуклых многоугольников, отсечение Сазерленда — Ходжмана, 8 секторов, Брахмастан по форме квартиры, сетка 32 пад и поясов)
- `src/vastu-data.js` — палитра, названия и формулы зон Анны Ромео, таблица 32 пад С. А. Балуты
- `src/renderer.js` — отрисовка интерактивного холста и экспорт итогового листа в PNG
- `src/pdf-loader.js` — локальное чтение изображений и первой страницы PDF
- `src/sample-plan.js` — встроенный учебный чертёж Г-образной квартиры
- `src/app.js` — управление касаниями (pinch-to-zoom двумя пальцами, перетаскивание углов, стрелка Севера) и панелью инструментов
- `tests/geometry.test.js` — модульные тесты геометрических расчётов
- `scripts/capture-screenshots.mjs` — автосъёмка скриншотов `390×844` и `1440×900` через Playwright
