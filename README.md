# Васту-карта · Анна Ромео

Веб-конструктор Васту-карты для учениц курса Анны Ромео, построенный по методу школы С. А. Балуты.

## Что умеет конструктор

- **Открытие своего плана квартиры**: принимает планировку от застройщика, скан БТИ и ровные фотографии чертежа (`JPG`, `PNG`, `WebP`), а также файлы `PDF` (включая чёрно-белые сканы `CCITT G4`, `JBIG2` и `JPX`). Ваш план видите только вы: карта строится прямо в окне браузера, без передачи файлов на сервер.
- **Север по спутнику без онлайн-сервисов внутри сайта**: ученица делает скриншот дома в Яндекс Картах или Google Картах в режиме «Спутник» (север сверху), загружает его в конструктор и отмечает два угла одной наружной стены (точки «1» и «2») на снимке и на плане. Конструктор вычисляет точный поворот плана относительно географического Севера; запасным способом можно ввести градусы вручную или повернуть стрелку «С».
- **Контур квартиры любой формы**: отметка внутренних углов касаниями, перетаскивание углов, вставка новой точки на стене, отмена шагов (`Отменить` вместе с поворотом листа) и помощник прямых углов `90°`.
- **Точный расчёт по школе С. А. Балуты**:
  - геометрический центр реальной формы квартиры (Брахмабинду) со спокойной пометкой «Центр вне стен — покажите эту карту Анне» для редких П-образных и сдвоенных планировок;
  - **8 радиальных секторов по 45°** от географического Севера в палитре и формулах Анны Ромео;
  - **Брахмастан по форме квартиры** (`1/9` площади — внутренняя треть лучей к углам с отсечением по наружным стенам);
  - **Сетка наложения пад** (`32` пады по `11,25°` вокруг центра, плюс отключаемые концентрические пояса `1/9 · 3/9 · 5/9 · 7/9` и баллы пад С. А. Балуты).
- **Итоговая карта «Север сверху» и скачивание PNG**: готовая карта разворачивается Севером вверх (с переключателем «Как на листе плана») и сохраняется в файл `karta-kvartiry-ГГГГ-ММ-ДД.png` через системное меню `Поделиться` на телефоне, прямое скачивание или полноэкранный показ для удержания пальцем во встроенных браузерах мессенджеров.
- **Сохранение работы на устройстве**: план, углы, Север и настройки автоматически сохраняются в `IndexedDB` / `localStorage` и восстанавливаются при повторном открытии страницы.

## Локальный запуск

Понадобится **Node.js 18+**.

```bash
# Установить зависимости
npm install

# Собрать локальные шрифты, legacy-модуль PDF с WASM-декодерами и папку dist/
npm run build

# Прогнать модульные тесты
npm test

# Запустить локальный сервер на http://127.0.0.1:4173
npm start
```

## Сборка для статического хостинга (Render Static Site)

- **Build Command**: `npm ci && npm run build`
- **Publish Directory**: `dist`
- Сайт полностью статический и автономный: внешние CDN, карты и серверный код не используются.

## Состав файлов

- `index.html` — разметка интерфейса, схема «Север по спутнику» и диалоговые окна
- `styles/main.css` — фирменный стиль Анны Ромео (бордовый `#422326`, тонкое золото `#CABC90`, кремовый `#F4F2ED`, адаптация под портретный и альбомный телефон и компьютер)
- `styles/fonts.css`, `assets/fonts/` — локальные шрифты `Cormorant` и `Manrope`
- `vendor/` — локальная `legacy`-сборка `pdf.js` и `WASM`-декодеры сканов (собираются скриптом `build.mjs`)
- `src/geometry.js` — геометрия контура, расчёт Севера по двум отрезкам стены, центр квартиры, 8 секторов, Брахмастан по форме квартиры и сетка 32 пад
- `src/state-helpers.js` — история «Отменить» с поворотом листа, проверка поля градусов и имя файла сохранения
- `src/storage.js` — автосохранение и восстановление работы в `IndexedDB` и `localStorage`
- `src/vastu-data.js` — палитра и формулы зон Анны Ромео, таблица 32 пад С. А. Балуты
- `src/renderer.js` — отрисовка интерактивного холста (без наложения подписей) и экспорт листа `PNG`
- `src/pdf-loader.js` — открытие изображений и первой страницы `PDF` с контролем лимита памяти iOS и пустых страниц
- `src/sample-plan.js` — программно отрисованный учебный план Г-образной квартиры
- `src/app.js` — логика вкладок, касаний, сопоставления по спутнику и сохранения карты
- `tests/geometry.test.js` — модульные тесты
- `scripts/capture-screenshots.mjs` — автопроверка браузером и съёмка контрольных скриншотов
