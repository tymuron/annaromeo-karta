# Васту-карта · Анна Ромео

Веб-конструктор Васту-карты для учениц курса Анны Ромео, построенный по методу школы С. А. Балуты.

## Что умеет конструктор

- **4 последовательных шага («1. План» → «2. Север» → «3. Контур стен» → «4. Карта»)**: пока план не загружен, шаги 2–4 неактивны с подписью «сначала шаг 1», а завершённые шаги отмечаются галочкой `✓`. На телефоне во время постановки точек рабочее поле с планом занимает более 80% высоты экрана, а панель шага сжимается в одну строку с подсказкой и кнопками «Отменить» и «Готово».
- **Открытие своего плана квартиры**: принимает планировку от застройщика, скан БТИ и ровные фотографии чертежа (`JPG`, `PNG`, `WebP`), а также файлы `PDF` (включая чёрно-белые сканы `CCITT G4`, `JBIG2` и `JPX`). Загруженные планировки и спутниковые снимки никуда по сети не отправляются — весь расчёт выполняется прямо на открытой странице.
- **Север строго по спутнику без онлайн-сервисов внутри сайта**: ученица делает скриншот дома в Яндекс Картах или Google Картах в режиме «Спутник» (север сверху), загружает его в конструктор и отмечает два угла одной достаточно длинной наружной стены (точки «1» и «2») сначала на снимке, затем на плане, после чего сверяет направление «С». Конструктор вычисляет точный поворот плана относительно географического Севера и показывает угол разворота дома относительно сторон света (ручной ввод градусов и ручной поворот стрелки «С» отключены).
- **Контур квартиры любой формы**: отметка внутренних углов касаниями (включая короткие стены лоджий и ниш), перетаскивание углов, вставка новой точки на стене, раздельная отмена шагов контура (`Отменить` не сбивает Север и точки стены, а отмена поворота листа возвращает лист, контур и Север вместе) и помощник прямых углов `90°`.
- **Точный расчёт по школе С. А. Балуты**:
  - геометрический центр реальной формы квартиры (Брахмабинду) со спокойной пометкой «Центр вне стен — покажите эту карту Анне» для редких П-образных и сдвоенных планировок;
  - **8 радиальных секторов по 45°** от географического Севера в палитре и формулах Анны Ромео;
  - **Брахмастан по форме квартиры** (`1/9` площади — внутренняя треть лучей к углам с чистым внешним контуром и отдельной пометкой, если Брахмастан прижат к наружной стене);
  - **Сетка наложения пад** (`32` пады по `11,25°` вокруг центра с размещением всех 32 номеров на сохранённой картинке, плюс отключаемые концентрические пояса `1/9 · 3/9 · 5/9 · 7/9` и баллы пад С. А. Балуты).
- **Итоговая карта «Север сверху», скачивание и отправка PNG**: готовая карта разворачивается Севером вверх (с переключателем «Как на листе плана») и сохраняется в файл `karta-kvartiry-ГГГГ-ММ-ДД.png` (на Android и компьютере — прямое скачивание файла + отдельная кнопка «Поделиться», на iPhone — системное меню с сохранением в Фото, во встроенных браузерах мессенджеров — полноэкранный показ для удержания пальцем).
- **Автосохранение черновика**: план, углы, Север и настройки автоматически сохраняются в `IndexedDB` / `localStorage` браузера и восстанавливаются при повторном открытии страницы.

## Локальный запуск

Понадобится **Node.js 18+**.

```bash
# Установить зависимости
npm install

# Собрать локальные шрифты, полифилы и legacy-модуль PDF с WASM-декодерами в папку dist/
npm run build

# Прогнать модульные тесты
npm test

# Запустить локальный сервер на http://127.0.0.1:4173
npm start
```

## Публикация

- Публикация настроена из репозитория **`https://github.com/tymuron/annaromeo-karta`** на **Render** (Static Site):
  - **Build Command**: `npm ci && npm run build`
  - **Publish Directory**: `dist`
- Ученицы открывают конструктор по адресу **`https://karta.annaromeovastu.com`** (через «дверь», работает в России), а не по адресу `onrender.com`.
- Сайт полностью статический и автономный: внешние CDN, карты и серверный код внутри конструктора не используются.

## Состав файлов

- `index.html` — разметка интерфейса, схема «Север по спутнику» и диалоговые окна
- `styles/main.css` — фирменный стиль Анны Ромео (бордовый `#422326`, тонкое золото `#CABC90`, кремовый `#F4F2ED`, адаптация под портретный и альбомный телефон и компьютер)
- `styles/fonts.css`, `assets/fonts/` — локальные шрифты `Cormorant` и `Manrope`
- `src/pdf-polyfills.mjs`, `vendor/` — полифилы для Safari/iOS (`Promise.withResolvers` и др.), локальная `legacy`-сборка `pdf.js`, обёртка воркера `pdf.worker.entry.mjs` и `WASM`-декодеры сканов (собираются скриптом `build.mjs`)
- `src/geometry.js` — геометрия контура, расчёт Севера и разворота дома по двум отрезкам стены, центр квартиры, 8 секторов, внешний контур Брахмастана и сетка 32 пад
- `src/state-helpers.js` — логика 4 шагов, миграция старых черновиков на Север по спутнику, раздельная история «Отменить» (контур отдельно от поворота листа), проверка длины стены, короткие стены и выбор способа скачивания
- `src/storage.js` — автосохранение и восстановление черновика в `IndexedDB` и `localStorage`
- `src/vastu-data.js` — палитра и формулы зон Анны Ромео, таблица 32 пад С. А. Балуты
- `src/renderer.js` — отрисовка интерактивного холста и экспорт листа `PNG` со всеми 32 номерами пад
- `src/pdf-loader.js` — открытие изображений и первой страницы `PDF` с контролем лимита памяти iOS и пустых страниц
- `src/sample-plan.js` — программно отрисованный учебный план Г-образной квартиры
- `src/app.js` — логика вкладок, касаний, сопоставления по спутнику и сохранения карты
- `tests/geometry.test.js` — модульные тесты
- `scripts/capture-screenshots.mjs` — автопроверка браузером и съёмка контрольных скриншотов
